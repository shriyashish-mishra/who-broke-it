No bullshit: what's proven, and what isn't

Open-source tools lie by omission. The incident above is fiction and labeled as such. This is the real status. (Full evidence and how to re-run it)

✓ Verified

  • Claude Code, OpenAI Codex CLI, Cursor Agent, OpenCode and Google Antigravity were each run end to end over MCP and the CLI protocol, judged from wbi's and git's recorded state, not from the agent's word. Those runs found real problems (a sandbox that blocks .git, missing attribution over MCP) that were fixed or documented. Run record · adapters and required settings
  • Linux, macOS and Windows CI, including a 24-process database stress test.
  • Sync run against real GitHub and gitlab.com with two clones each: signed batches, a forged batch rejected, the team allow-list, --force-with-lease compaction, and concurrent claim races with exactly one winner every time (17/17 checks on each host).
  • The merge gate on real pull requests in the public demo repo; installable via curl, Homebrew and go install.
  • Every transcript in the "Real CLI" section is captured from a real run.

◌ Not proven

  • Other versions of those tools, and Windows for any agent.
  • Bitbucket and self-hosted GitLab/git for sync (see VERIFICATION.md).
  • Slack and Discord notifications: tested against local webhook mocks, not the real services.
  • Linear and Jira sync: not built (generic webhooks are).
  • Authorized teammates are trusted with each other: signatures stop outsiders and forgery, not insiders.
  • Intent is cooperative: agents must declare it; wbi verify and wbi check enforce scope after the fact.
  • The demo scripts are bash (Linux and macOS); the Go tests run on Windows in CI.
  • The incident story on this page is a fictional, scripted demo with simulated output.
